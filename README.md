# دفتر

نسخة أولى لتعلّم بناء نظام عروض أسعار وفواتير بالـ HTML وCSS وJavaScript، بدون مكتبات أو باك إند.

## تشغيل محلي

من مجلد المشروع شغّلي `python -m http.server 8765 --directory src` ثم افتحي `http://localhost:8765`.

## الملفات

- `src/index.html`: هيكل الواجهة العربية.
- `src/style.css`: تصميم متجاوب وتنسيق الطباعة.
- `src/app.js`: الشاشات والنماذج والتفاعل.
- `src/model.js`: حساب الإجمالي والخصم والمدفوع والمتبقي.
- `src/storage.js`: الحفظ المحلي والتحقق من النسخ الاحتياطية. يمكن استبدال المستودع بطلبات API لاحقًا، مع جعل استدعاءات الواجهة غير متزامنة.
- `src/demo-data.js`: العملاء والخدمات والفواتير والدفعات التي توضح استخدام التطبيق.
- `src/assets/`: شعار دفتر والخطوط المحلية مع رخصة الخط.

العملة الافتراضية هي الدولار الأمريكي وتظهر البيانات التجريبية مرة واحدة مع الحفاظ على البيانات الحالية.

## تجربة مقترحة

1. أضيفي عميلًا من صفحة العملاء.
2. أضيفي خدمة «تصميم موقع» بسعر 3000.
3. أنشئي عرض سعر، واختاري الخدمة، وضعي خصمًا 10٪.
4. احفظيه وحوّليه لفاتورة، ثم سجّلي دفعة 1000. الإجمالي 2700 والمتبقي 1700.
5. من «عرض» اختاري الطباعة، ثم «حفظ بتنسيق PDF» في نافذة المتصفح.
6. صدّري نسخة احتياطية من الإعدادات، وأعيدي تحميل الصفحة للتأكد من استمرار البيانات.

## حدود النسخة

البيانات مرتبطة بالمتصفح والجهاز وعنوان الموقع؛ لا توجد مزامنة. العملة إعداد عام لا يحوّل المبالغ. واجهة التطبيق عربية، وعناوين قالب الطباعة متاحة بالعربية والإنجليزية. المعلومات التي تكتبينها لا تُترجم. النسخة لا تضيف ضريبة أو دفعًا إلكترونيًا أو إرسالًا للعملاء. حذف المستند يحتاج تأكيدًا ولا توجد سلة محذوفات. تصدير PDF يتم عبر طباعة المتصفح.

## توسّع لاحق

إضافة ضريبة اختيارية، وتتبع حالات عروض الأسعار، وإدارة أوسع للعملاء والخدمات، ثم تسجيل الدخول وحفظ البيانات في قاعدة بيانات ومزامنتها.
